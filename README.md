# Hotel Management System (Core Java, OOP)

## 📌 Project Overview
The **Hotel Management System** is a console-based Java application designed to manage basic hotel operations such as room availability, guest check-in, and guest check-out. The project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** concepts in Java by using modular classes and efficient object management.

## 🚀 Features

- View available rooms
- Guest check-in functionality
- Guest check-out functionality
- Room occupancy tracking
- Guest information management
- Menu-driven console interface

## 🛠️ Technologies Used

- **Programming Language:** Core Java
- **Concepts Applied:** Object-Oriented Programming (OOP)
    - Encapsulation
    - Classes and Objects
    - Constructors
    - Methods
    - Data Abstraction
- **Development Environment:** IntelliJ IDEA / Eclipse / VS Code
